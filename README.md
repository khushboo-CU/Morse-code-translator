# Morse Code Translator

A modern and responsive Morse Code Translator built using HTML, CSS, and JavaScript. This application allows users to convert plain text into Morse code and Morse code back into readable text.

## Features

- Convert Text to Morse Code
- Convert Morse Code to Text
- Simple and User-Friendly Interface
- Responsive Design
- Real-Time Translation
- Error Handling for Invalid Inputs

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How to Use

1. Enter text or Morse code in the input field.
2. Click the translate button.
3. View the translated output instantly.
